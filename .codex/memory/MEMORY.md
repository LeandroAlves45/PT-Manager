# PT Manager: memória local do Codex

Este ficheiro existe apenas por compatibilidade com o Codex CLI. A memória operacional do
projeto vive em `.claude/memory/MEMORY.md` e nas notas de sessão em `.claude/memory/Sessions/`.
`AGENTS.md` já direciona qualquer agente a ler `.claude/memory/MEMORY.md` no início da sessão.

Este ficheiro não deve conter histórico próprio. Se precisares de registar algo, escreve em
`.claude/memory/MEMORY.md`.
