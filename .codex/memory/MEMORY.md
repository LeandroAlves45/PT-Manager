# PT Manager: memória local do Codex

Este ficheiro existe apenas por compatibilidade com o Codex CLI.

## Bootstrap (igual a Cursor e Claude Code)

1. `AGENTS.md`
2. `.claude/memory/ACTIVE.md`
3. `.claude/memory/MEMORY.md`
4. Sprint Pack activo: `.claude/project/sprints/.../README.md`
5. Skill `.claude/skills/sprint-context/SKILL.md` em tarefas de sprint/fase

A memória operacional **não** vive aqui. Escrever sempre em `.claude/memory/`.

## Ferramentas

- **Codex:** planear, blueprints, review completa
- **Cursor:** dúvidas e ajustes pontuais durante implementação manual
