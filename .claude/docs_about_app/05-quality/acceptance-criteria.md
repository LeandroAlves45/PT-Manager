# Critérios de aceitação

Estado: à espera do teu preenchimento (2026-10-14).

Formato: Dado / Quando / Então. Um critério observa comportamento. Não repete o requisito inteiro. Liga ao `RF` ou à `RN`.

Os dois primeiros são rascunhos da visão, para veres o formato. Confirma ou reescreve.

## CA-001 — Isolamento

- Liga a `RF-001` e `RN-001`.
- Dado que o trainer A está autenticado.
- Quando pede um cliente do trainer B.
- Então a resposta não traz os dados desse cliente.
- A tua correcção: **por preencher**

## CA-002 — Sem pagamento do cliente na app

- Liga a `RF-006`.
- Dado que o trainer cria um pack para o cliente.
- Quando o cliente usa o portal.
- Então não há passo em que o cliente pague ao trainer dentro da app.
- A tua correcção: **por preencher**
